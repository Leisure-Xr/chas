# 更新记录

## 0.10.0

- VS Code 不再启动、控制或读取外部浏览器；Cloudflare 验证改为扩展内手动参数管理。
- 验证设置页增加 Request Headers 解析、保存并测试、仅保存和详细 DevTools 获取步骤。
- 明确区分 `/latest.json`、主文档和其他接口的请求标头差异，只要求同一次验证中的 Cookie 与 User-Agent。
- PyCharm 工具栏增加宽/中/窄窗口自适应，赛车改为单一道路内的连续转向。

## 0.9.0

- Cloudflare 命令改为直接打开参数管理页，支持从 Request Headers 解析 Cookie 与 User-Agent、逐项清除和全部清除。
- VS Code 不会启动或控制浏览器；手动参数通过公开 `/latest.json` 测试后才更新 SecretStorage，并提供完整的 Windows DevTools 获取说明和示意图。
- 新增当前公开主题的限时分享码，可选 10 分钟、1 小时、24 小时或 7 天，并支持从剪贴板或输入框导入。
- 五款小游戏统一增加开始倒计时、暂停、重新开始、失焦自动暂停和持久化最高分；改进 2048 撤销、贪吃蛇加速、单道路赛车平滑转向、跳跃物理及扫雷首击安全与双击展开。
- 增加共享游戏核心一致性测试与第三方玩法参考声明。

## 0.8.0

- Cloudflare 验证通过后保留独立 Chromium 游客会话，并在阅读器使用期间保持最小化运行。
- 最新、热门、分类、搜索、主题和滚动续载统一改为在已验证浏览器内请求，避免 Cookie 转交 Node.js 后因浏览器指纹变化再次返回 403。
- 只有浏览器内 `/latest.json` 返回有效公开 JSON 后才确认验证成功。
- 浏览器被关闭或验证失效时恢复验证入口；清除验证、关闭阅读器或退出 VS Code 时结束浏览器并清理临时配置。
- 保留原有 SecretStorage 键和游客 Cookie 白名单，继续拒绝登录字段。

## 0.7.0

- 新增默认关闭的休息提醒，可随机等待 31–60 分钟。
- 新增 2048、贪吃蛇、车道闪避、像素跳跃和扫雷。
- 工具栏可切换提醒，也可随时打开小游戏。

## 0.6.0

- 首页、热门和分类主题列表支持滚动续页。
- 列表使用 Discourse 返回的 `more_topics_url`，避免猜测分页规则。
- 返回时恢复点击前的页面 DOM、已加载主题和精确滚动位置，不再重新请求第一页。

## 0.5.0

- 增加阅读器内返回按钮和页面历史记录。
- 主题根据完整帖子索引分批续载，支持滚动到底自动加载和手动加载更多。
- 刷新主题时会重新获取帖子索引与首批内容。
- 默认使用更紧凑、低干扰的 VS Code 原生信息流样式，并可切换舒适密度。

## 0.4.0

- 自动验证会读取临时游客会话所需的 Cloudflare Cookie 和匿名论坛会话 Cookie。
- 手动模式支持粘贴完整 Cookie，但仅保留游客白名单字段。
- 未检测到登录标记时可保留匿名 `_forum_session`；Stripe 和登录相关 Cookie 始终丢弃。

## 0.3.0

- Cloudflare 验证改为自动获取，无需手动复制参数。
- 使用临时 Chrome 游客会话并通过本机调试协议读取 `cf_clearance` 和 User-Agent。
- 验证完成后自动关闭浏览器并删除临时浏览数据。
- 在无法启动兼容浏览器时保留手动粘贴方式。

## 0.2.0

- 增加 Cloudflare 手动验证流程。
- `cf_clearance` 和 User-Agent 使用 VS Code SecretStorage 保存。
- 明确拒绝保存论坛登录 Cookie。

## 0.1.0

- 支持最新、热门、分类和搜索。
- 支持在 VS Code 内阅读公开主题。
- 所有请求均为无 Cookie 的游客请求。
