# 隐私阅读排版修复记录

## 问题与修复

- 公共 CSS 仅设置颜色，正文继续继承论坛字体，标题却单独指定等宽字体。现在四站共用系统无衬线字体；正文 14px / 1.7 行距，主题标题 18px，作者与时间 12px，代码独立使用等宽字体。
- 嵌套 Markdown、行内字号和各站默认标题、引用、列表间距仍会覆盖正文排版。公共层统一这些规则，保留加粗、强调、标题层级和正文图片原色。
- 隐藏身份元素后，原布局仍保留占位。修复 Discourse 固定正文宽度/浮动、NodeSeek 列表缩进/不换行、V2EX 头像及回复数表格列、重复间隔；宽表格与长代码独立滚动。
- NodeSeek 的整个帖子嵌在评论列表中，浏览器误将正文列表当成第二级列表。正文列表层级现在只按正文内部的嵌套计算。
