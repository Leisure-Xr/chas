# PyCharm 版论坛游客阅读器

在 PyCharm 中以游客身份阅读 LINUX DO、NodeSeek、V2EX 和 IDC Flare 的公开内容。插件原名“LINUX DO 游客阅读器”，插件 ID 和工具窗口 ID 保持不变，可原地升级并保留窗口位置。

## 安装与升级

当前版本为 **16.3**。[下载 ZIP 与校验值](../README.md#下载)。`dist/` 只保留当前安装包，旧版可从 Git 历史获取。

在 **Settings > Plugins > 齿轮菜单 > Install Plugin from Disk...** 中选择 ZIP 并重启，不要解压。通过 **View > Tool Windows > 论坛游客阅读器** 打开阅读器。

声明支持 PyCharm 2022.3–2026.3（构建号 `223–263.*`），需要 JetBrains Runtime 自带 JCEF；缺少 JCEF 时工具窗口会给出提示。具体已测试范围见 [验证记录](../qa/docs/pycharm-validation.md)。

升级保留既有历史和收藏。回退到单论坛 16.0 时，非 LINUX DO 的历史与收藏会在旧版下次保存时丢弃，收藏目录保留。

## 支持的论坛

在“⋯ > 切换论坛”中选择站点；点击另一个受支持论坛的链接时自动切换。标题栏、导航和搜索随站点更新，下次打开回到上次的论坛。

| 论坛 | 导航 | 站内搜索 | 加密分享 |
| --- | --- | --- | --- |
| [LINUX DO](https://linux.do/) | 最新、热门、分类 | 支持 | 支持 |
| [NodeSeek](https://www.nodeseek.com/) | 最新（新评论）、新帖、精品 | 游客停用 | 支持 |
| [V2EX](https://www.v2ex.com/) | 全部、最热、节点 | 游客停用 | 支持 |
| [IDC Flare](https://idcflare.com/) | 最新、热门、分类 | 支持 | 支持 |

只阅读游客可见内容。登录重定向和真正的拒绝访问会显示可重试错误页，不绕过登录墙或阅读等级限制。

## 隐私阅读布局

四站共用跟随 IDE 主题的黑白灰布局：正文 14px、主题标题 18px、作者和时间 12px，代码保持等宽；长链接换行，代码块与宽表格在自身区域横向滚动。段落、小标题、引用和列表采用统一间距。列表标题、帖子标题、正文及原文加粗均显示为正常字重。

隐藏站点顶栏、侧栏、页脚、广告、头像、徽章及身份装饰；用户名弱化显示，正文中的截图、附件、Onebox 和技术图片保持原色。NodeSeek 保留版块链接。切换 IDE 主题时原地更新，不刷新网页或重置滚动位置。

“⋯”菜单可以切换原始网页。隐私样式导致内容不可见时会回退为原始布局；连续异常最多自动重试三次，之后可点击“重新应用隐私阅读布局（当前已回退）”。正常加载或 SPA 渲染暂态会继续等待内容恢复。

顶栏保留返回、前进、刷新和“⋯”，下一行提供站点导航和搜索。历史、收藏、分享、提醒、游戏、布局和会话操作集中在“⋯”菜单。

## 验证与加载问题

插件不给页面导航挂请求处理器，网页按内置浏览器的默认方式请求。16.2 为读取响应头给每次导航挂了处理器，LINUX DO 的 Cloudflare 因此每次导航都要求验证，刚拿到的验证结果也不被承认，页面会在验证页上反复循环；隔离实测中去掉处理器后与普通浏览器一样直接放行。

Cloudflare 验证期间保留真实页面，插件不往验证页里执行任何脚本（探针、加载遮罩、阅读样式和小游戏都会等验证通过后再加载）。NodeSeek 自动等待 45 秒，其余站点 20 秒；自动刷新和跳转不会重置首次验证期限，提示栏会显示 Cloudflare 已要求验证的轮次。

验证页由标题（“Just a moment…”“请稍候…”）或地址中的 `__cf_chl_` 参数识别，识别后立即切换验证状态。自动等待结束后提示勾选页面中的验证框，保留验证脚本和可能稍后出现的复选框。可以“重新验证”“停止验证”或切换站点；成功后隐藏提示并恢复阅读布局。重新验证、刷新和重试都会重新请求去掉验证参数的地址。可用“在浏览器打开”检查网络与站点；外部浏览器的验证结果不会同步到插件。没有验证页特征的 403/503 稍候即显示错误页，网络错误同样显示错误页。

首次打开工具窗口时，导航会等内置浏览器创建完成后再发出，不会再在 30 秒后误报“加载超时”。

## 历史、收藏与分享

历史跨论坛共用，最多保存 60 条公开页面，可按标题或 URL 搜索、重新打开、复制或清空。同一主题的楼层链接规范化去重，验证及登录地址不会入库。

收藏夹以顶部标签切换目录，默认显示全部收藏；主题标题最多两行，下方显示目录、站点和时间。搜索覆盖所有目录名、站点名、标题与 URL，清空后恢复目录选择。可以新建、重命名、删除目录，打开、复制或移除主题；同一主题可以加入不同目录，移除一条不影响其他目录和历史。表单与操作后原地更新，保留搜索及滚动；Tab、Enter、Esc 可用于键盘操作。

四个论坛的公开主题都可通过“⋯ > 分享当前主题”生成密码加密内容：

1. 选择 10 分钟、1 小时、24 小时或 7 天，设置至少 12 字符的密码，或生成 20 位密码。
2. 分开传送分享内容与密码；密码不会保存。
3. 接收方通过“打开加密分享”导入，插件打开同一论坛的同一主题。

LINUX DO 主题的分享格式不变，与 VS Code 版及 16.2 互通。NodeSeek、V2EX 和 IDC Flare 的分享带有站点信息，需用 PyCharm 16.3 或更新版本打开；VS Code 版和旧版会提示“加密分享内容无效”，不会误开 LINUX DO 上同编号的主题。

分享使用 AES-256-GCM 和 600,000 轮 PBKDF2-HMAC-SHA256，不包含 Cookie、请求档案或阅读历史。到期后拒绝导入，不能撤回已打开的公开主题；旧的未加密分享格式不受支持。

## 休息提醒与小游戏

提醒默认关闭，开启后随机等待 31–60 分钟，可跳过或延后 10 分钟。“⋯”菜单也可直接打开五款小游戏：2048、贪吃蛇、单道路赛车、像素跳跃和扫雷。游戏支持自适应尺寸、高 DPI、暂停、重新开始、键盘和屏幕操作、失焦自动暂停及本地最高分；调整窗口或主题不重置对局。

## 数据与资源

- 不请求、保存或提交账号凭据，拦截登录、注册和认证页面及相关写请求。
- 会话开始、重置和项目关闭时，只清理四个论坛及其子域名的 JCEF Cookie。JCEF Cookie 库由 PyCharm 共享，因此这些域名的既有会话也会被清理；其他站点和外部浏览器不受影响，日志不记录 Cookie 值。
- 本地保存布局与提醒设置、历史、收藏及游戏最高分，不保存正文或登录状态，无遥测。
- 隐藏工具窗口不会释放内嵌 Chromium；关闭项目或移除工具窗口内容时释放浏览器。

## 构建与测试

在 `pycharm/` 目录执行：

```bash
./scripts/build-local.sh
./scripts/verify-package.sh
```

默认使用 `/Applications/PyCharm.app` 的 SDK；其他位置可设置 `PYCHARM_HOME`。构建会运行 Java 测试，输出 `build/distributions/linuxdo-guest-browser-pycharm-16.3.zip`，并校验包内资源与源码一致。`build.gradle.kts` 支持 Gradle 开发及 CI 构建。

[QA 说明](../qa/README.md) 提供多论坛布局、收藏夹原生面板和真实 IDE 测试方法。共享游戏的参考项目与许可证见 [第三方声明](THIRD_PARTY_NOTICES.md)。
